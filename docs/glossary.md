# Glossary

| Term                     | Meaning                                                                                                                                                                                                                                                                  |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Selected root            | The one project directory selected by an optional `--root` override or discovery from the current directory. Discovery selects the nearest canonical or Git marker, with provider workspace markers as guarded fallbacks; without markers it uses the current directory. |
| User home (`$HOME`)      | The operating-system user directory, which is never a selected root.                                                                                                                                                                                                     |
| Threadpoint state home   | Private product state selected by `THREADPOINT_HOME` or `--home`; it does not select a project.                                                                                                                                                                          |
| Shared lane              | `AGENTS.md` and `.agents/`, suitable for version control.                                                                                                                                                                                                                |
| Local lane               | `AGENTS.local.md` and `.agents.local/`, intentionally ignored.                                                                                                                                                                                                           |
| Provider artifact        | A known provider-native file below the selected root.                                                                                                                                                                                                                    |
| Provider entrypoint      | A native file through which a provider finds shared guidance. Threadpoint may inspect it but does not create it.                                                                                                                                                         |
| Stage                    | A private, immutable-scope review copy of one native artifact.                                                                                                                                                                                                           |
| Commit                   | The explicit write of one reviewed stage to its canonical target.                                                                                                                                                                                                        |
| Reviewed source snapshot | The source bytes recorded with a successful commit and used by prune.                                                                                                                                                                                                    |
| Prune                    | Removal of an unchanged native source after its reviewed content is committed.                                                                                                                                                                                           |
| Backup                   | A versioned local snapshot used by restore and recovery.                                                                                                                                                                                                                 |
